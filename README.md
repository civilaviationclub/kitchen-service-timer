# Kitchen and Service Timer

Civil Aviation Club mobile timing observations, migrated from the original service timer. Five sequential timing checkpoints, monthly summary, searchable observation log, CSV export and JSON backup/restore.

All observations and preferences stay in this browser on this device. No upload endpoint, analytics or cloud synchronization. The public repository includes app code and generic icons only. Export a backup from the old app and restore it in the new app to move records. Keep backups private.

Installable on supported browsers; open online once to cache app files for offline use.
